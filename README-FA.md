# چک‌لیست کامیونت

پروژه اولیه اندروید (Kotlin) برای ساخت APK با GitHub Actions.

## امکانات نسخه اولیه
- چک‌لیست‌های روزانه، ماهانه و سالانه
- ذخیره وضعیت تیک‌ها و یادداشت‌ها روی گوشی
- سه یادآور مدارک: معاینه فنی، بیمه شخص ثالث، پروانه فعالیت
- زمان هشدار ۷ روز قبل، ساعت ۹ صبح
- بازیابی زمان‌بندی یادآورها پس از راه‌اندازی مجدد گوشی
- اشتراک‌گذاری گزارش متنی از طریق برنامه‌های نصب‌شده

## ساخت APK با GitHub
1. محتویات ZIP را از حالت فشرده خارج کنید.
2. تمام فایل‌ها و پوشه‌ها را در ریشه یک مخزن GitHub با نام `KamyoonChecklist` بارگذاری کنید.
3. در مخزن، وارد تب Actions شوید و گردش‌کار `Build Android APK` را اجرا کنید (یا پس از push به شاخه main خودکار اجرا می‌شود).
4. پس از موفقیت، در صفحه اجرای workflow بخش Artifacts فایل `KamyoonChecklist-debug-apk` را دریافت کنید.
5. ZIP آرتیفکت را باز کنید؛ `app-debug.apk` فایل نصب برنامه است.

## نکته
این نسخه اولیه است و پیش از استفاده واقعی باید روی گوشی آزمایش شود. برای هشدار دقیق در Android 12 به بالا ممکن است لازم باشد مجوز Alarms & reminders از تنظیمات گوشی فعال شود. در Android 13 به بالا مجوز اعلان نیز درخواست می‌شود.
